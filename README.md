## `01` · OVERVIEW

Repository ini merupakan proyek **Tugas Promosi** yang mendemonstrasikan bagaimana sebuah website portofolio modern dapat di-hosting secara gratis, cepat, dan aman menggunakan **GitHub Pages**.

Website dibangun dalam satu berkas mandiri (`index.html`) menggunakan **Tailwind CSS** dengan desain minimalis monokrom, dukungan *Dark/Light Mode*, animasi *scroll reveal*, serta widget asisten interaktif (`zvim Assistant`).

> **Live Preview:**  
> `https://<username-github>.github.io/<nama-repository>/` *(ganti sesuai username & nama repo kamu)*
